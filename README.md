# jari — 창업 자리 폐업률

서울 가게(외식·미용·의원·약국·편의점·PC방 등 인허가 업종)가 문을 연 뒤 3년 안에 얼마나 문을 닫았는지를 조건별(상권·업종·면적·층·체인·건물 이력)로 보여주고, 지번별 개폐업 이력을 조회하는 서비스.

- 화면: `docs/` (GitHub Pages)
- 데이터 파이프라인: `pipeline/` (LOCALDATA 인허가 + 서울시 상권 데이터)
- DB: Supabase (`supabase/schema.sql`, 테이블 접두사 `jari_`)

자료: 행정안전부 LOCALDATA 인허가, 서울 열린데이터광장 상권분석서비스. 공공데이터 집계이며 개별 가게의 미래를 예측하지 않습니다.
